# Replay-Audio Dropdown Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the "🔊 Replay audio" `st.expander` (a full-width tab that renders *below* the assistant's reply) with a small dropdown-arrow button that sits *beside* the reply text and opens a floating popover containing the same audio player.

**Architecture:** Single call site in `Template-bot/files/lucelec_rag_bot.py`'s `process_chat_message()`. Split the reply row into two columns (`text | arrow`) whenever TTS is enabled, using a `st.empty()` placeholder in the arrow column so the button can be filled in *after* audio generation finishes, without breaking the existing "text renders immediately, audio streams in a moment later" order.

**Tech Stack:** Streamlit 1.54.0 (`st.popover`, available since 1.27 — no version bump needed), same TTS engines already wired up (`generate_google_tts`, `generate_elevenlabs_tts`). No new dependencies.

```python
# After:
            # GENERATE ASSISTANT REPLY
            with st.chat_message("assistant", avatar=bot_avatar):
                with st.spinner("Retrieving…"):
                    excel_records = st.session_state.get("excel_records", [])
                    out = answer(q, index, user, excel_data=excel_records, language=sim_language)

                tts_on = st.session_state.accessibility_settings.get("tts")

                # Reserve a narrow side column for the replay-audio dropdown
                # arrow up front, before audio exists, so the arrow lands
                # beside the reply text instead of on a new line below it.
                # The slot stays empty (no visible arrow) if TTS is off or
                # generation fails.
                if tts_on:
                    text_col, audio_col = st.columns([20, 1])
                    with text_col:
                        st.markdown(out["reply"])
                    audio_slot = audio_col.empty()
                else:
                    st.markdown(out["reply"])
                    audio_slot = None

                # --- TTS Generation with Engine Router ---
                if tts_on:
                    with st.spinner("Generating audio..."):
                        engine = st.session_state.accessibility_settings.get("tts_engine", "Google (Free)")

                        # Route to the correct engine
                        if engine == "ElevenLabs (Credits)":
                            audio_data = generate_elevenlabs_tts(out["reply"])
                        else:
                            # Passes sim_language to gTTS
                            audio_data = generate_google_tts(out["reply"], language=sim_language)

                        # Fill the reserved arrow slot with a popover so the
                        # player stays hidden until the user opens the
                        # dropdown to replay it, while autoplay still fires
                        # on first generation.
                        if audio_data and audio_slot is not None:
                            with audio_slot.popover("🔽"):
                                st.audio(audio_data, format="audio/mp3", autoplay=True)
                # --------------------------------------------------
```
